## Complete Lab Curriculum

### 🛠️ Lab 0: Environment Setup
**Files**: `Lab00_Environment_Setup.md`
- JDK installation and configuration
- Environment variables (PATH, JAVA_HOME)
- IDE setup (VS Code, IntelliJ, Eclipse)
- First program compilation and execution
- Development workflow understanding

### 🚀 Lab 1: Main Method Fundamentals
**Files**: `01_MainMethod_Theory.md`, `02_BasicMainMethod_Examples.java`, `03_Lab_Exercises.md`, `04_Compilation_Execution_Guide.md`, `05_Sample_Solutions.java`
- Main method signature breakdown
- Command line arguments handling
- Basic program structure
- Compilation and execution process
- Practical exercises and solutions

### 📊 Lab 2: Data Types and Variables
**Files**: `Lab02_DataTypes_Variables.md`, `Lab02_DataTypes_Examples.java`
- Primitive data types (int, float, double, boolean, char)
- Non-primitive types (String, Arrays)
- Variable declaration and initialization
- Constants using final keyword
- Type casting and conversion
- Variable scope and naming conventions

### ⚡ Lab 3: Operators
**Files**: `Lab03_Operators.md`, `Lab03_Operators_Examples.java`
- Arithmetic operators (+, -, *, /, %)
- Relational operators (==, !=, >, <, >=, <=)
- Logical operators (&&, ||, !)
- Assignment operators (=, +=, -=, *=, /=, %=)
- Unary operators (++, --, +, -, !)
- Ternary operator (? :)
- Operator precedence and associativity

### 🔄 Lab 4: Control Flow Statements
**Files**: `Lab04_ControlFlow.md`, `Lab04_ControlFlow_Examples.java`
- Conditional statements (if, if-else, switch)
- Loop statements (for, while, do-while)
- Loop control (break, continue)
- Nested control structures
- Practical applications and patterns

### 💬 Lab 5: Basic Input/Output
**Files**: `Lab05_InputOutput.md`, `Lab05_InputOutput_Examples.java`
- Output operations (println, print, printf)
- Scanner class for input
- Reading different data types
- Input validation techniques
- Formatted output and String formatting
- Interactive program development

## Quick Start Guide

### For Students:
1. **Start with Lab 0**: Set up your development environment
2. **Progress sequentially**: Complete labs in order (0→1→2→3→4→5)
3. **Read theory first**: Understand concepts before coding
4. **Practice with examples**: Run and modify provided code
5. **Complete exercises**: Apply what you've learned
6. **Verify solutions**: Check your work against sample solutions

### For Instructors:
1. **Pre-lab preparation**: Ensure all students have proper environment setup
2. **Theory explanation**: Use markdown files for concept explanation
3. **Live coding**: Demonstrate examples in class
4. **Guided practice**: Help students through exercises
5. **Assessment**: Use provided solutions for evaluation
6. **Progressive teaching**: Build concepts incrementally

## Common Issues and Solutions

### Compilation Errors
- **Class name mismatch**: Ensure class name matches filename
- **Missing semicolons**: Check for proper statement termination
- **Case sensitivity**: Java is case-sensitive

### Runtime Errors
- **Main method not found**: Check main method signature
- **Array index out of bounds**: Validate command line arguments
- **Number format exception**: Handle invalid numeric inputs
